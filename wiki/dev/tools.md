# Developer tools

Editors, Git UI, Nix language tooling and AI coding CLIs.

## Micro

- Micro uses its default colourscheme (`dotfiles/micro/settings.json`).
- Micro rewrites files atomically, so the whole directory is linked.
  `dotfiles/micro/.gitignore` is an allow-list, so only `settings.json` is
  tracked. Backups, history and `bindings.json` stay local.

## Zed

`settings.json` sets Berkeley Mono and the font sizes (UI 16, buffer 14);
Zed's default theme follows the system light/dark mode. Zed follows KWin's
150% scale itself. Zed rewrites its settings file, so the whole directory is
linked. `$EDITOR` is `zeditor --wait`, so Git and other callers block until
the tab is closed.

## VS Code

Plain package; it follows KWin's scale on Wayland. `settings.json` sets
Berkeley Mono. Extensions stay in `~/.vscode/`, outside Git.

## Lazygit

No managed config; Lazygit writes its own `~/.config/lazygit/` on first run.

## SSH

Home Manager generates `~/.ssh/config`, which includes `~/.ssh/config.local`.
Hosts tied to personal accounts go in that local file, outside Git, as plain
OpenSSH blocks (`Host`, `HostName`, `User`). Shareable hosts can go in
`programs.ssh.settings` in `modules/home/ssh.nix` instead.

## nvtop

```sh
nvtop      # F2 setup, F10 or q to quit
```

## Agent workflows

Coding agents read `AGENTS.md` (Claude Code via `CLAUDE.md`) and use the skills
in `.agents/skills/` for commits, rebuilds, troubleshooting, packaging, new
hosts and docs. The routing table in [AGENTS.md](../../AGENTS.md#skill-routing)
says which skill handles which task.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Micro settings not saved to Git | expected for ignored files. Extend the allow-list in `dotfiles/micro/.gitignore` |
| nixd shows no completions | editor not pointed at nixd; `nix develop` provides it too |
| `git commit` returns at once with an empty message | `$EDITOR` lacks `--wait`: `echo $EDITOR` |
